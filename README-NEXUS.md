## Tentang NEXUS

NEXUS dibangun dengan konsep *futuristic minimal*: tampilan gelap bernuansa teknologi, aksen biru dan cyan, serta tata letak yang dirancang agar nyaman digunakan di komputer maupun perangkat seluler.

Fokus utama website ini bukan hanya menampilkan hasil, tetapi juga perjalanan eksplorasi dan pengembangan kemampuan.

## Fitur

- **Personal introduction** — profil singkat dan perkenalan.
- **Interactive futuristic avatar** — avatar bergaya manusia futuristik yang memberikan reaksi animasi saat diklik atau disentuh.
- **Interests** — area yang memperkenalkan ketertarikan pada AI, teknologi, dan eksplorasi digital.
- **Projects** — dokumentasi proyek yang pernah dikembangkan.
- **Journey** — ringkasan perjalanan belajar dan eksplorasi.
- **Interactive 3D Earth** — globe Bumi berbentuk bola 3D yang dapat diputar dengan sentuhan atau mouse, dengan penanda Indonesia.
- **Application preview** — gambar dokumentasi aplikasi *Lensa XII IPS 1* dapat dibuka melalui tulisan pada kartu proyek aplikasi.
- **Contact links** — tautan menuju media sosial dan email.

## Teknologi

Website dibuat sebagai halaman statis dengan:
- **HTML** untuk struktur konten.
- **CSS** untuk desain, tata letak, dan responsivitas.
- **JavaScript** untuk navigasi, interaksi avatar, pratinjau gambar aplikasi, dan kontrol globe.
- **Three.js** untuk visualisasi Bumi 3D.
- **GitHub Pages** untuk publikasi website.

Sebagian besar tampilan menggunakan HTML, CSS, dan JavaScript dalam satu file `index.html` agar mudah dikelola dan diperbarui melalui perangkat Android. Three.js dan tekstur Bumi dimuat dari sumber eksternal sehingga fitur globe memerlukan koneksi internet.

## Menjalankan secara lokal

Karena ini merupakan website statis, tidak diperlukan proses build khusus.

1. Unduh atau clone repository ini.
2. Buka `index.html` melalui browser atau jalankan menggunakan server statis lokal.
3. Pastikan perangkat terhubung ke internet agar pustaka Three.js dan tekstur Bumi dapat dimuat.

## Publikasi

Website ini dipublikasikan menggunakan GitHub Pages.

Untuk memperbarui website:
1. Perbarui file `index.html`.
2. Unggah file ke direktori utama repository.
3. Commit perubahan ke branch publikasi yang digunakan GitHub Pages.
4. Buka kembali alamat website setelah proses publikasi selesai.
