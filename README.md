# NEXUS Portfolio

Starter website satu file untuk workflow Android-first.

## Isi
- `index.html` — seluruh homepage, CSS, dan JavaScript dalam satu file.
- Tidak memerlukan proses build.
- Objek 3D menggunakan Three.js dari CDN; jika WebGL/CDN tidak tersedia, website menampilkan fallback visual.

## Sebelum dipublikasikan
1. Buka `index.html`.
2. Cari `EMAIL_KAMU_DI_SINI`.
3. Ganti dengan alamat email milikmu.
4. Ganti kartu proyek contoh dengan proyek nyata saat sudah tersedia.

## Publikasi GitHub Pages
1. Buat repository baru bernama `nexus-portfolio`.
2. Upload `index.html` ke root repository (bukan di dalam folder lain).
3. Buka Settings → Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu proses publikasi. URL biasanya `https://USERNAME.github.io/nexus-portfolio/`.

Website ini sengaja dibuat satu file agar lebih mudah diunggah dan diedit melalui HP Android.
