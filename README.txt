NEXUS PORTFOLIO V2 — PANDUAN UPLOAD ANDROID

Isi folder:
- index.html : seluruh website dalam satu file.

CARA MEMPERBARUI WEBSITE GITHUB PAGES:
1. Buka https://github.com/personlabs/nexus-portfolio
2. Buka file index.html.
3. Pilih ikon pensil (Edit this file), atau gunakan Add file > Upload files untuk mengganti file.
4. Jika upload file baru, pastikan nama tepat index.html dan pilih Replace jika diminta.
5. Commit changes.
6. Tunggu sebentar, lalu buka https://personlabs.github.io/nexus-portfolio/

PENTING:
- Website lama akan tergantikan setelah index.html versi baru di-commit. Simpan salinan file lama terlebih dahulu jika ingin bisa kembali.
- Avatar futuristik dibuat dari CSS (bukan model manusia 3D eksternal), tetapi memiliki animasi saat diklik/disentuh.
- Globe menggunakan Three.js dari CDN. Jika koneksi/CDN/WebGL tidak tersedia, fallback globe tetap muncul.
- Proyek aplikasi kelas belum memiliki tautan publik, jadi ditampilkan sebagai proyek tanpa tautan.
- Kontak menggunakan detail yang diberikan pemilik website.
